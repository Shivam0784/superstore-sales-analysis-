# superstore-sales-analysis

## Project Overview
An end-to-end data analytics project analysing 9,994 retail orders to find sales trends, top products, and loss-making items using Excel, SQL, Python and Power BI.

## Tools Used
- Excel — data cleaning, pivot tables, charts
- SQL Server (SSMS) — data querying and analysis
- Python — pandas, matplotlib, seaborn for EDA
- Power BI — interactive dashboard

## Problem Statement
- Which product category earns the most?
- Which region has highest sales?
- Which products are losing money?
- Which months have lowest sales?

## Key Findings
- Technology is the top category ($836K sales)
- West region leads with 31.58% of total sales
- Tables and Bookcases are loss-making products
- December has highest sales (holiday season)
- February has lowest sales every year

## Files in this Repository
- superstore_cleaned.csv — cleaned dataset
- superstore_analysis.ipynb — Python analysis
- sql_queries.sql — all SQL queries
- dashboard_screenshot.png — Power BI dashboard
